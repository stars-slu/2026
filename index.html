Data Sources

General

  • Data Is Plural
    • - spreadsheet, check second sheet for interactive search tools.
  • Tidy Tuesday
  • Our World in Data — no API; clean bulk CSV downloads, readable directly from GitHub
  • Kaggle — kaggler package or CLI

Local

  • City of St. Louis Open Data
  • St. Louis County Open Data
  • Missouri DESE (School) Data
  • Missouri Census Data Center — demographic, economic, and geographic data with custom tabulation tools
  • Missouri Data Portal — Socrata-based; use RSocrata
  • Missouri Dept. of Health & Senior Services — vital stats, chronic disease, behavioral health
  • MERIC — labor market, industry, and occupational data for Missouri

Global / Intergovernmental

  • World Bank — WDI package; raw API at api.worldbank.org/v2/
  • UN Data — UNdata package or OData-style REST API
  • OECD — OECD or rsdmx package; SDMX-based API
  • IMF — imfr package or SDMX JSON API
  • Eurostat — eurostat package — very polished

US Government

  • Data.gov
  • Census Bureau — tidycensus (ACS, decennial) — the gold standard
  • CDC WONDER — wondr or raw REST; also CDC's SODA API via RSocrata
  • FRED (Federal Reserve) — fredr package — clean key-based API
  • BLS — blsR or raw JSON API
  • data.gov / Socrata portals — RSocrata works across hundreds of portals

Health-Specific

  • Medicare provider data
  • IHME / GBD — bulk CSV downloads; structured and well-documented
  • NCBI / PubMed / GenBank — rentrez package
  • ClinicalTrials.gov — ctrdata or raw REST v2 API

Environment & Earth Science

  • NOAA — rnoaa package
  • NASA EarthData — nasapower, MODISTools
  • GBIF (biodiversity) — rgbif package
